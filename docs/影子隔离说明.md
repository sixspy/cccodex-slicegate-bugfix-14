# 影子隔离说明（乙锁定）

> 本说明一经写入当天不许换。偏离本说明的请求一律拒绝，并记审计事件「影子口径偏了」。

## 锁定口径：乙

影子水位与正式水位**同表**（`watermarks`），但**强制影子标记**（`kind`：`正式` / `影子`）：

1. **默认列表过滤影子**：`GET /api/watermarks` 只返回 `kind='正式'` 的行，即正式展示集合；
   影子水位只能走独立隔离区 `GET /api/watermarks/shadow`，绝不混入正式展示集合。
2. **试跑只写影子**：`POST /api/slices/{id}/trial` 只插入 `kind='影子'`、`is_current=0` 的行，
   影子推进不算正式消费进度。
3. **晋升原子切换标记**：`POST /api/watermarks/{id}/promote` 在同一事务内先退该消费方旧现行、
   再把影子行切换为 `kind='正式'` 且 `is_current=1`，**禁止双现行并存**；
   库层以部分唯一索引 `ux_watermarks_one_current`（`consumer` 唯一，`kind='正式' AND is_current=1`）兜底。
4. **占坑排队**：影子晋升与正式放行同时提交同一消费方槽位时 FIFO 排队，
   后手水位行 `contended=1` 并记审计事件「影子争用」。
5. **偏离即拒**：正式列表夹带影子参数、对非影子行发起晋升、换隔离口径（甲/乙互切）、
   当天重写说明，一律 409 拒绝并记「影子口径偏了」。

## 对账同源

水位台、审计台、目录旁注、策略条、详情条均取自同一组接口
（`/api/watermarks`、`/api/watermarks/shadow`、`/api/watermarks/overview`、`/api/audit`），
两边不得各认各的数。

## 反面（甲锁定，未采用）

影子水位只进影子表、正式水位查询排除影子行。本仓未采用；任何切换到甲的请求按偏离处理。
